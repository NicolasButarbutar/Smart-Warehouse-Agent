# Dokumentasi Tambahan

Folder ini menyimpan dokumen pendukung di luar laporan Milestone resmi (yang dikumpulkan terpisah dalam format PDF ke ECourse), misalnya:

- Diagram arsitektur atau graf gudang yang lebih detail.
- Catatan desain (design notes) untuk keputusan teknis tertentu.
- Ringkasan hasil evaluasi/eksperimen pada milestone lanjutan.

Laporan resmi Milestone 1 (Problem Framing, PEAS, formulasi ruang keadaan) berada di luar repositori ini sebagai berkas `GrupXX-Tugas01.pdf` yang diunggah ke ECourse.
